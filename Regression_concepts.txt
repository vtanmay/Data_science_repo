===== Imp concepts in regression ====

1. covariance - All you can really tell from covariance is if there is a positive or negative relationship.
-- A problem with covariance as a statistical tool alone is that it is challenging to interpret. This leads us to
 the Pearson’s correlation coefficient

2. Pearson correlation coefficient -
will give you a value for the relationship. 1 is perfect
    # correlation and 0 is no correlation calculate covariance and Pearson correlation coefficient -
    # https://machinelearningmastery.com/how-to-use-correlation-to-understand-the-relationship-between-variables/
    # calculate Pearson's correlation - The pearsonr() SciPy function can be used to calculate the Pearson’s
    # correlation coefficient between two data samples with the same length
3. Correlation - how strong is the relationship between variables.
==== ML Model performance ===
4. Model Performance : Compute R-Square(=1 best fit, R-Square = 1 - sse/sst) R square - it is a statistical
    # measure of how close the data are to the fitted regression line. It is also known as the coefficient of
    # determination
5. Model over fitting - model will work very good on train data but will fail on unseen data.
6 adjusted R-squared - R squared is constant and adjusted R squared starts decreasing means we are adding too many predictors/
 independent variables in the model.
7. Collinearity -  is a condition in which some of the independent variables are highly correlated.
--- how to detect multicollinearity - find out correlation coefficients between independent variables.
# if correlation coef is greater than 0.7 or less than -0.7, then we can say there is multicollinearity.
# instead of looking at the collinearity matrix, we can use VIF - Variance Inflation Factor.
VIF is applied on a model , and not on variables.

==== overall flow =====
1. start reading the data set.
2. create liner regression with single variable model. calculate R square for the model.
3. create multi variable model.
4. check for multicollinearity and model overfiting. calculate correlation coef and VIF.
5. finalize the model.
6. make predictions using the model.
7. Evaluate the model - In case of regression models, model will be evaluated in terms of R square and RMSE.
 Regression model means my output is continuous and numerical.
